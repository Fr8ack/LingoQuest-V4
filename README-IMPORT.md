# نقل LingoQuest V4 إلى Google AI Studio — دليل عملي

تاريخ التحضير: 2026-10-20. **لم يُرفع المشروع تلقائيًا إلى Google AI Studio أو GitHub من هذه المحادثة.** الملفات أدناه مُعَدّة لعملية النقل يدويًا.

## المسار الموصى به: GitHub → Google AI Studio

1. فك ضغط `LingoQuest-V4-Google-AI-Studio.zip` على الكمبيوتر. تأكد أن `index.html` و`app.js` و`package.json` ظاهرة داخل المجلد مباشرة.
2. افتح GitHub وسجّل الدخول، ثم أنشئ مستودعًا **خاصًا (Private)** باسم `lingoquest-ar` أو اسم تختاره، وبدون إضافة README منفصل إن كنت سترفع README الخاص بالمشروع.
3. من صفحة المستودع اختر `Add file` ثم `Upload files`، وارفع **محتويات المجلد المفكوك** (ملفات المصدر نفسها) لا ملف ZIP فقط. تأكد من أن `index.html` و`package.json` في الجذر.
4. افتح https://aistudio.google.com/، ثم `Build` وحدد تطبيق ويب. من مربع الطلب اضغط علامة `+` ثم `Import from GitHub`، واربط GitHub عند طلب الأذونات، واختر المستودع. هذا هو مسار الاستيراد الموثق رسميًا في 2026.
5. بعد ظهور ملفات الكود داخل AI Studio، افتح `GOOGLE_AI_STUDIO_MASTER_PROMPT.md` وانسخ محتواه كاملًا إلى محادثة Build ثم أرسله.
6. اشترط أولًا رؤية النسخة الحقيقية V4 مع اختبار الاستيراد والتقدم، ولا تسمح بإعادة إنشاء التطبيق بدلًا من استيراده.
7. من إعدادات AI Studio يمكنك تفعيل المزامنة مع GitHub عند الحاجة، ثم احفظ نسخة ZIP جديدة بعد اعتماد أي إصدار جديد.

**مهم:** رفع ملف ZIP كملف إلى مربع الطلب لا يضمن أن المنصة ستنشئ جميع ملفات مشروعك في مساحة التحرير. استخدم GitHub import ما أمكن، أو أضف الملفات يدويًا داخل محرر الملفات إن أتاح ذلك.

## التشغيل المحلي إن رغبت

- لا يحتاج إلى `npm install` لأن المشروع الأصلي Vanilla JS ويعتمد خادم Node دون تبعيات إضافية.
- `npm run check`
- `npm run dev`
- `npm run build`

يستخدم المشروع `server.mjs` و`build.mjs` لتشغيل وبناء الموقع دون تبعيات خارجية، ومصدر الواجهة الحقيقي Vanilla HTML/CSS/JS. استخدم `http://localhost:3000` بعد `npm run dev`؛ ويمكن بديلًا استخدام `python -m http.server 8000`.

## النقل بين الأصول المختلفة وحفظ تقدم المتعلم

- تخزين V4 الحالي في localStorage بالمفتاح `lingoquest_ar_v1` و**لا ينسخ نفسه بين نطاقين مختلفين**.
- لانتقال التقدم: افتح نسخة V4 القديمة > `حسابي` > `تصدير JSON`، ثم داخل النسخة المنشورة الجديدة > `حسابي` > `استيراد JSON`.
- انتبه: ملفات تقدم الطلاب قد تتضمن أسماءهم؛ لا ترفع ملفات طلاب حقيقية إلى GitHub ولا ترسلها إلى الذكاء الاصطناعي. استخدم بيانات تجريبية فقط.

## الأمان والنشر

- لا توجد مفاتيح API في V4 الحالية؛ في V5 استخدم Secrets على الخادم ولا تعرض `GEMINI_API_KEY` في المتصفح.
- الاستيراد لا يعني نشر الموقع للناس. ميزات استدعاء Gemini المدفوعة قد تتسبب بتكاليف عند الاستخدام والنشر.
- لا تقدم اختبار 24 سؤالًا بوصفه شهادة CEFR. ولا تنشر بيانات أطفال قبل ضوابط واضحة للخصوصية والأمان.
