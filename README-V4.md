# مغامرة إنجليش — LingoQuest V4

**تجربة لعبة تعلم اللغة الإنجليزية بالعربية؛ ليست برنامج اعتماد أو تقييم CEFR معياريًا.**

## التشغيل

**ملف واحد:** افتح `lingoquest-standalone.html` في متصفح Chrome أو Edge. لا يحتاج إنشاء حساب لدى طرف خارجي أو مفتاح API. تعتمد الأصوات على خدمات وأصوات المتصفح المتوفرة، وقد لا تتوفر في كل جهاز/وضع دون إنترنت.

**ملفات مشروع:** قدم `index.html` مع `content.js` و`adventure-content.js` و`app.js` و`styles.css` و`icon.svg` و`manifest.webmanifest` و`sw.js` إلى خادم ملفات ثابت. يمكن مثلًا استخدام `python -m http.server 8000` من مجلد المشروع ثم فتح `http://localhost:8000/`.

## محتوى المشروع

| العنصر | العدد |
|---|---:|
| اختبار مستوى أولي | 24 سؤالًا |
| دروس V1–V3 التجريبية | 12 درسًا / 72 سؤالًا |
| حروف A–Z | 26 حرفًا / 4 وحدات |
| تركيب كلمات الأصوات القصيرة | 5 وحدات / 20 كلمة / 40 سؤالًا |
| قصص V4 | 12 / 60 سؤال فهم ومفردات |
| محادثات V4 | 12 / 36 جولة تفاعلية |
| قواعد قراءة V4 | 5 / 30 سؤالًا |

القصص والمحادثات متاحة بحسب مستوى المتعلم. القصة الثانية والمحادثة الثانية من مستوى واحد تتطلبان اجتياز الأولى على الترتيب. تمثل الأنشطة V4 مسارًا مساعدًا، ولا تغير مستوى المتعلم الرسمي داخل التطبيق حتى يجتاز تحدي الترقية الأساسي.

## نقل التقدم V3 → V4

قد تظهر حساباتك القديمة تلقائيًا إذا فتحت النسختين ضمن نفس أصل الموقع. بخلاف ذلك استخدم **حسابي → تصدير JSON** في V3، ثم **حسابي → استيراد JSON** في V4. افحص حسابك بعد النقل واحتفظ بالنسخة الأصلية.

## التشغيل والجودة

```
node --check app.js
node validate-content.mjs
node validate-adventure.mjs
node test-flow.mjs
python test-browser-v4.py
```

اختبارات المتصفح تتطلب Chromium وPlaywright مثبتين. توجد في ملفات V4 لقطتا `screenshot-v4-desktop.png` و`screenshot-v4-mobile.png`.

## معلومات مهمة

- يتجنب الموقع أي محتوى منسوخ من تطبيقات تعليمية أخرى؛ القصص والحوارات الأصلية مخصصة للمشروع.
- التعلم باستخدام Web Speech / تعرّف المتصفح على الصوت؛ لا تقدّم النتائج الحالية درجة نطق دقيقة.
- ليس في هذه النسخة استدعاء لنموذج ذكاء اصطناعي، ولا قاعدة بيانات أو حساب متعدد الأجهزة.
- يستحسن أن يجربها المستخدم بأسماء مستعارة لا ببيانات أطفال أو طلاب حقيقيين قبل تجهيز حماية بيانات مناسبة.
- احتفظ بـ `CHECKPOINT-V4.md` وملف ZIP كاملًا للرجوع في المرحلة التالية.
